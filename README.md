## 到手先验四步，别只查 ipinfo 的 type

拿到 IP 之后的第一件事不是上业务，是验货。常见的做法是打开 ipinfo 看 `type` 字段是不是 `isp`，这个做法有用但不够。

`type` 描述的是拥有该 ASN 的组织类型，不保证每一个具体 IP。同一家运营商网络里既有家庭宽带也有商业线路，一个 `type: isp` 的地址照样可能是机房转租的。判断时要几个指标一起看：

1. **看 `org` 字段里的 ASN 与运营商名。** Comcast 是 AS7922、AT&T 是 AS7018、Verizon 是 AS701、Charter/Spectrum 是 AS20115、CenturyLink/Lumen 是 AS209。显示这几家属于正常，显示 DigitalOcean、AWS、Azure 一类就是机房段。
2. **看 `hosting` 字段。** 返回 `true` 是很强的数据中心信号，直接退换。
3. **查黑名单与欺诈评分。** Scamalytics、IPQualityScore 各跑一次，命中黑名单或分数偏高的地址不要用在主账号上。
4. **查 DNS 归属和浏览器指纹。** 出口地区与 DNS 解析地区要一致；时区、语言、WebRTC 泄露的地址要和出口对齐。

四步都过，再小量跑一两周，稳了才放量。ASN 和欺诈分的截图按账号归档，后面申诉或续费时能拿出来。

另外提前知道一件事：Sixtynet 官方关闭了 ICMP 应答，ping 不通，常规的 ping 延迟和丢包测试做不了。有一篇测评用其他方式测到三网平均延迟在 170–180ms，电信最低 165ms；这个数字只代表当时的线路状态。
